draw(ignore_zeros=False, preal=0, mode: str = 'logical') → None

Draw the quantum state components.

Prints the elements of the state vector along with their probabilities.

Parameters:

  • ignore_zeros (bool, default False) – If True, prints only non-zero amplitudes.

  • preal (int, default 0) – State index used to make its amplitude a positive real number. If -1, the global phase factor is not adjusted.

  • mode ({'logical', 'physical'}, default 'logical') – Quantum state representation mode to draw.

Examples

>>> qstate.draw()
c[00] = +0.7071+0.0000*i : 0.5000 |++++++
c[01] = +0.0000+0.0000*i : 0.0000 |
c[10] = +0.0000+0.0000*i : 0.0000 |
c[11] = +0.7071+0.0000*i : 0.5000 |++++++
...
>>> qstate.draw(ignore_zeros=True)
c[00] = +0.7071+0.0000*i : 0.5000 |++++++
c[11] = +0.7071+0.0000*i : 0.5000 |++++++
